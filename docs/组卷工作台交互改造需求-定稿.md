# 组卷工作台交互改造需求文档（定稿）

> 状态：待用户最终确认后开发
> 改造目标：把右侧常驻的「试卷模板 / 细目表组卷 / 组卷体检」三个工具改为触发式，让 A4 画布始终占满右侧、试卷预览清晰可见。

---

## 一、整体布局改造

### 1.1 右侧移除工具抽屉
- 删除右侧 `#paperToolDrawer` 区域（原试卷模板 / 细目表组卷 / 组卷体检 三标签抽屉）。
- 右侧区域仅保留：
  - 顶部操作栏（统计、留白、批量设分、保存/历史、模板入口、体检入口、导出按钮）。
  - 下方 A4 画布（占满右侧全部剩余高度）。

### 1.2 左右宽度
- 左侧保持 55%（选题区：配置栏 + 全库/已选试题流）。
- 右侧保持 45%（预览与导出区，A4 画布全高）。

---

## 二、细目表组卷 → 左侧按钮弹窗

### 2.1 入口位置
- 在左侧配置栏「智能一键抽卷」输入框所在行，新增按钮「细目表组卷」。

### 2.2 弹窗交互
- 点击打开玻璃拟态 Modal「细目表组卷」。
- 弹窗内是可编辑表格，每行字段：
  - 知识点（可空，多值逗号分隔 OR 匹配）
  - 题型（单选/多选/填空/解答/不限）
  - 难度（普通/易错/挑战/强基/不限）
  - 解题方法（可空，多值逗号分隔）
  - 数量（1–20）
- 支持：加行、删除行。
- 底部按钮「按细目表抽题入篮」：按各行条件抽题，跨行去重、优先引用少、已入篮不重复；结果 Toast 提示（入篮数 / 缺口数）。
- 抽题完成后关闭弹窗，左侧「已选试题」与右侧 A4 画布即时刷新。

### 2.3 状态
- 细目表行数据存 `PaperStore.specRows`，刷新后可恢复。

---

## 三、试卷模板 → 右侧导出前弹窗（可编辑 + 可新增）

### 3.1 入口位置
- 右侧操作栏新增按钮「选择试卷模板」。

### 3.2 弹窗交互
- 点击打开 Modal「选择试卷模板」。

### 3.3 模板结构（每个模板含两部分）
**A. 卷面元信息（meta）**
| 字段 | 含义 | 必填 |
|---|---|---|
| name | 模板名称 | ✅ |
| paper_type | 版式：exam_19(19题高考卷含答题卡) / exam(常规卷) / quiz(日常小练) | ✅ |
| total_score_target | 目标总分（数字） | ✅ |
| solution_space_default | 默认留白：0.0(不留白)/3.0(紧凑)/7.0(标准) | ✅ |

**B. 细目表行（spec_rows，可多行，可选）**
| 字段 | 含义 | 必填 |
|---|---|---|
| knowledge | 知识点（可空，多值逗号分隔） | 否 |
| question_type | 题型（可空=不限） | 否 |
| difficulty | 难度（可空=不限） | 否 |
| solve_method | 解题方法（可空） | 否 |
| count | 该组抽题量（1–20） | ✅ |

### 3.4 应用粒度（用户已确认）
- **默认**：应用模板只覆盖卷面参数（总分 + 留白 + 版式）。
- **细目表作为可勾选项**：
  - 应用时弹窗内提供勾选框「同时加载模板细目表」。
  - **勾选** → 把模板的 spec_rows 加载进细目表弹窗（只加载、不自动抽题），用户可改知识点/难度后再手动抽题。
  - **不勾选** → 模板细目表完全不加载，保持工作区干净。
- 应用后 A4 画布按 meta 参数即时重渲染；用户仍可手动调整分值、留白。

### 3.5 可编辑 + 可新增（用户已确认）
- **内置模板**以卡片列出，可「应用」或「编辑」（编辑态下 meta 与 spec_rows 全字段可改）。
- **新增预设**按钮：空白表单逐项输入上表字段，保存即存入个人预设库（接口 `/api/paper/save-template`）。
- **个人预设**列表：可「应用 / 编辑 / 删除」（接口 `/api/paper/templates`、`DELETE /api/paper/template/{id}`）。

### 3.6 不保留 AI 双向细目表分析条（用户已确认）
- 移除智能抽取后 A4 画布上方的「双向细目表与考点覆盖分析」文本框及相关逻辑（`meta.ai_analysis` 展示）。

---

## 四、组卷体检 → 右侧按钮弹窗（用户已确认不强制）

### 4.1 入口位置
- 右侧操作栏新增按钮「组卷体检」（常驻显示，报告不默认展开）。

### 4.2 弹窗交互
- 点击打开 Modal「组卷体检报告」。
- 报告内容（复用现有统计逻辑）：
  - 总分与目标分对比
  - 题型分布（题数/分值）
  - 难度分布条
  - 知识点覆盖
  - 疑似重复题提示
- 弹窗内可设置「目标分」并实时看到校验结果。
- 关闭弹窗不影响当前组卷状态。

### 4.3 不强制
- 保存试卷前不强制弹体检；体检纯属用户手动选择项。

## 五、交互流程图（定稿）

```
组卷排版工作台
├── 左侧 55%：选题区
│   ├── 组卷配置栏（标题/学段章节/题型难度/搜索/智能抽取/[细目表组卷按钮]）
│   └── 全库试题流 / 已选试题流
└── 右侧 45%：预览与导出区
    ├── 操作栏
    │   ├── 统计（总分/题数/难度比）
    │   ├── 留白 / 批量设分
    │   ├── [组卷体检按钮] → 弹窗报告
    │   ├── 保存 / 历史试卷库
    │   ├── [选择试卷模板按钮] → 弹窗（含细目表勾选）
    │   └── 导出按钮组（PDF/Word/LaTeX）
    └── A4 画布（占满右侧全部剩余高度）
```

## 六、数据与接口

- `PaperStore.specRows`：细目表行，弹窗关闭后仍保留。
- `PaperStore.activeToolTab`：改造后移除。
- `PaperStore.meta.total_score_target`：体检目标分校验。
- `meta.ai_analysis` / `meta.ai_model_used`：移除展示与清理逻辑。
- 模板接口：`/api/paper/templates`（GET）、`/api/paper/save-template`（POST）、`/api/paper/template/{id}`（DELETE）。
- 细目表抽题：`/api/paper/batch-select`（POST）。

## 七、视觉与体验

1. 弹窗统一使用项目已有玻璃拟态（glass-modal）风格。
2. 按钮使用项目已有 `glass-btn-primary` / 次级样式。
3. 右侧操作栏保持紧凑，避免再次挤压 A4 画布。
4. 窄屏/平板下 Modal 宽度自适应（`max-w-lg` / `max-w-2xl`）。
5. 弹窗打开时背景主界面可见 A4 画布但不可交互（标准 modal overlay）。

## 八、验收标准

- [ ] 右侧工具抽屉已移除，A4 画布占满右侧高度。
- [ ] 左侧「智能抽取」行出现「细目表组卷」按钮，点击打开细目表 Modal，可增删行并抽题。

- [ ] 模板 Modal 支持：内置模板应用/编辑、新增预设、个人预设应用/编辑/删除。
- [ ] 应用模板时可勾选「同时加载细目表」；勾选→加载进细目表弹窗不自动抽题；不勾→不加载。

- [ ] 右侧出现「组卷体检」按钮，点击弹出体检报告 Modal（5 项检查）。

## 九、已确认的用户决策记录

1. 预设模板可编辑、可新增（基于第六节字段结构）。
2. 模板应用粒度：默认仅覆盖总分与留白；细目表作为可勾选项（勾=加载不抽题，不勾=不加载）。
3. 组卷体检不强制，作为手动触发按钮。
4. 不保留 AI 双向细目表分析条。
5. 开发流程：先需求文档确认，再开发（用户明确要求）。
