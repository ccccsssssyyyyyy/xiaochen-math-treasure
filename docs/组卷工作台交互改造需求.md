# 组卷工作台交互改造需求文档

## 一、问题背景

当前「组卷排版工作台」右侧区域采用「三标签工具抽屉 + A4 画布」上下布局。用户实际加入题目后发现：

- 工具抽屉（试卷模板 / 细目表组卷 / 组卷体检）默认展开，最高可占右侧 45% 高度；
- A4 画布被严重压缩，已选试题的试卷效果几乎不可见；
- 三个工具并非每时每刻都需要：细目表只在抽题前配置、模板只在导出前选择、体检只需在组卷完成后偶尔检查。

因此需要将三个功能从常驻面板改造为**触发式、弹出式**入口，让右侧区域回归「试卷预览与导出操作」主体。

## 二、改造目标

1. **右侧不再常驻任何工具抽屉**，A4 画布占据右侧全部高度，试卷预览始终可见。
2. **细目表组卷**作为智能抽题的补充入口，放在左侧「智能抽取」附近。
3. **试卷模板**延迟到导出阶段再选择是否应用。
4. **组卷体检**由用户手动触发，以弹窗形式展示评估报告。

## 三、详细需求

### 3.1 右侧布局简化：移除工具抽屉

- 删除右侧 `#paperToolDrawer` 区域。
- 右侧区域仅保留：
  - 顶部操作栏（统计、留白、批量设分、保存/历史、导出按钮）。
  - 下方 A4 画布（占满剩余高度）。
- 左侧宽度保持 55%，右侧宽度保持 45%，但右侧全部用于预览与操作。

### 3.2 细目表组卷：改为左侧入口

**位置**：在左侧配置栏「智能一键抽卷」输入框所在行，新增一个按钮「细目表组卷」。

**交互**：
- 点击后弹出 Modal（玻璃拟态弹窗），标题为「细目表组卷」。
- Modal 内展示可编辑的细目表：
  - 每行可配置：知识点、题型、难度、解题方法、数量。
  - 支持增删行、清空、应用预设模板（如「周测/月考」预填行）。
- 配置完成后，点击「按细目表抽题」关闭弹窗并把题目加入试卷篮。
- 抽题结果以 Toast 提示（入篮数 / 缺口数）。

**状态**：细目表行数据仍保存在 `PaperStore.specRows` 中，刷新后可恢复。

### 3.3 试卷模板：延迟到导出阶段

**位置**：在右侧导出按钮区（PDF 预览 / Word 导出 / LaTeX 打包 之前或上方），新增「应用模板」区域。

**交互**：
- 默认不展开，显示一个按钮「选择试卷模板」。
- 点击后弹出 Modal「选择试卷模板」。
- Modal 内展示：
  - 内置模板：周测 100 分 / 月考 150 分 / 随堂练 50 分。
  - 个人预设模板列表（从 `/api/paper/templates` 读取）。
- 选择模板后，可选择「仅加载题型结构」或「覆盖总分与留白」。
- 应用后关闭弹窗，A4 画布按模板参数重新渲染。
- 用户仍可手动调整分值、留白，模板仅作为一次性应用，不会锁定设置。

### 3.4 组卷体检：改为手动触发弹窗

**位置**：在右侧操作栏新增一个按钮「组卷体检」。

**交互**：
- 按钮常驻显示，但体检报告不默认展开。
- 点击后弹出 Modal「组卷体检报告」。
- Modal 内展示当前试卷的：
  - 总分与目标分对比；
  - 题型分布（题数/分值）；
  - 难度分布条；
  - 知识点覆盖；
  - 疑似重复题提示。
- Modal 内仍允许设置「目标分」并实时看到校验结果。
- 关闭弹窗不影响当前组卷状态。

## 四、交互流程图

```
组卷排版工作台
├── 左侧 55%：选题区
│   ├── 组卷配置栏（标题/筛选/智能抽取/细目表入口）
│   └── 全库试题流 / 已选试题流
└── 右侧 45%：预览与导出区
    ├── 操作栏
    │   ├── 统计（总分/题数/难度比）
    │   ├── 留白 / 批量设分
    │   ├── 组卷体检（按钮 → 弹窗）
    │   ├── 保存 / 历史试卷库
    │   └── 选择模板（按钮 → 弹窗）/ 导出按钮组
    └── A4 画布（全高）
```

## 五、数据与状态

- `PaperStore.specRows`：细目表行数据，Modal 关闭后仍保留。
- `PaperStore.activeToolTab`：改造后不再需要，可移除或保留兼容（建议移除）。
- `PaperStore.meta.total_score_target`：用于组卷体检目标分校验。
- 模板数据仍通过 `/api/paper/templates` 与 `/api/paper/save-template` 交互。
- 体检报告计算逻辑复用现有 `renderPaperHealthCheck` 中的统计代码，仅输出目标从 DOM 改为 Modal 内 DOM。

## 六、视觉与体验要求

1. 弹窗统一使用项目已有的玻璃拟态（glass-modal）风格。
2. 按钮使用项目已有的 `glass-btn-primary` / `glass-btn-secondary` 样式。
3. A4 画布顶部操作栏保持紧凑，避免再次挤压预览区。
4. 在窄屏或平板视图下，Modal 宽度自适应（`max-w-lg` / `max-w-2xl`）。
5. 弹窗打开时，背景主界面仍可看到 A4 画布，但不可交互（标准 modal overlay）。

## 七、验收标准

- [ ] 右侧工具抽屉已移除，A4 画布占满右侧高度。
- [ ] 左侧「智能抽取」行出现「细目表组卷」按钮，点击可打开细目表 Modal。
- [ ] 细目表 Modal 内可增删改行并执行抽题，抽题后关闭弹窗并刷新左侧已选试题。
- [ ] 右侧导出区出现「选择试卷模板」入口，点击可打开模板 Modal。
- [ ] 选择模板后可应用题型结构与分值/留白，A4 画布即时更新。
- [ ] 右侧操作栏出现「组卷体检」按钮，点击弹出体检报告 Modal。
- [ ] 体检报告包含总分、题型、难度、知识点、重复题 5 项检查。
- [ ] `node --check static/js/paper.js` 通过。
- [ ] 首页 HTTP 200，刷新组卷工作台后新布局生效。

## 八、待确认问题

1. **细目表弹窗是否需要预设模板？** 例如「周测 / 月考」预填多行，减少用户每次从零输入。
2. **模板应用粒度？** 仅覆盖总分与留白，还是同时按模板预设题型自动抽题？
3. **组卷体检是否要在保存试卷前强制提醒？** 例如总分与目标分差值过大时点保存弹出体检报告。
4. **是否保留当前「细目表抽题后提示去体检」的文案？** 改造后可改为「抽题完成，新增 X 道」。
