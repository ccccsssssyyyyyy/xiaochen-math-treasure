# 组卷 Word 导出：解析图片误入学生版试卷 — 修复记录（2026-08-26）

## 现象
用户在录题页面把多张图片作为答案解析插入解析处，组卷 Word 导出后，这些图片出现在**学生版试卷**里（本应只出现在教师版解析区）。

## 根因
`mathbank/word_export_helper.py` 的 `_resolve_image_paths` 把三类图片**不加区分**全部塞进 `PreparedQuestion.images`：
- `image_paths`（题干图 + 解析图合并后的清单）
- `content` 中引用的图片
- `answer_markdown` 中引用的图片

随后 `add_question` 把这些图一律作为题干配图渲染到学生版；而 `add_answers` 又把解析文字里的 `![...]` 语法删掉，导致解析区反而没有图。

PDF 导出不受此影响：`paper_helper.py` 学生版只扫描 `content` 的图片，解析图不会进入学生版。

## 修复（仅 `mathbank/word_export_helper.py`，4 处）
1. `PreparedQuestion` 新增 `answer_images: list[Path]` 字段。
2. `_resolve_image_paths` 重写为返回 `(题干图, 解析图)` 分流：
   - `content` 中引用的图片 → 题干图（出现在学生版）
   - `answer_markdown` 中引用的图片 → 解析图（仅出现在教师版解析区）
   - 仅存于 `image_paths`、未被任一 markdown 引用的图片 → 保守归题干（兼容旧数据，避免丢图）
3. `_prepare_question` 分别接收 `images=题干图`、`answer_images=解析图`。
4. `add_answers` 在解析文字下方渲染 `answer_images`（解析图）；仅当 answer 为空且无解析图时才显示「暂无答案与解析」。
