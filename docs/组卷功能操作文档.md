# 小陈的数学宝藏 组卷功能操作文档

> 适用版本：本地备课工具（派生自 math-question-bank）  
> 访问地址：`http://127.0.0.1:8000`（本机启动 uvicorn 后）  
> 本文档面向教师日常备课场景，介绍从「选题 → 组卷 → 体检 → 保存 → 导出」的完整流程。

---

## 0. 两个工作台的区别

小陈的数学宝藏 顶部左侧有 **「小陈的数学宝藏 ▾」** 下拉，可切换两个工作台：

| 工作台 | 用途 | 入口 |
| --- | --- | --- |
| **题库工作台** | 录入 / 编辑 / 检索题目，浏览所有题 | 默认进入 |
| **组卷工作台** | 把题目拼成一份卷子、排版、导出 PDF/Word | 下拉选「组卷工作台」 |

组卷相关的一切操作都在 **组卷工作台** 中进行。本工具已在题库工作台顶部加了「试题篮」提示条，可在不切换工作台的情况下把题加入试卷，再点「去组卷」进入排版界面。

---

## 1. 进入组卷工作台

1. 顶部左上角点击 **小陈的数学宝藏 ▾** → 选择 **组卷工作台**。
2. 首次进入是空白卷，右侧 A4 画布提示「请在左侧点击加入试卷添加题目」。
3. 界面为**双大栏布局**：
   - **左侧（55%）**：**组卷配置栏**（标题/学段章节/题型难度/搜索/智能抽取/细目表组卷按钮）+ **全库试题流**（选题目主区域），空间更宽、题干展示更完整。
   - **右侧（45%）**：上方是**操作栏**（统计/留白/批量设分/组卷体检/选择试卷模板/保存/历史/导出），下方是**A4 画布**（占满剩余高度，已选试题预览与排版始终清晰可见）。
   - 三个工具（试卷模板 / 细目表组卷 / 组卷体检）均改为**触发式弹窗**，不常驻占用画布空间。

## 2. 三种选题方式

### 方式 A：手动在题库里点选（最直观）

在「全库试题」列表中，每道题右上角有 **「加入试卷」** 按钮（悬停卡片时出现）：

- 点击 → 题目进入右侧试卷，按钮变为 **「已入卷」**（绿色），可再点移出。
- 已选中的题在卡片上有品牌色边框高亮。
- 顶部切到 **「已选试题 (N)」** 标签可只看已入卷的题，并支持 **上移/下移** 调整顺序。

> 在 **题库工作台** 也能直接「入卷」：每张题卡悬停时显示「入卷」按钮，顶部还会出现「试题篮：N 题 · 去组卷」提示条，点「去组卷」即跳转排版界面。

### 方式 B：细目表组卷（先定计划，再自动凑题）

适合「我要出一份周测，单选 8 道 + 填空 4 道 + 解答 4 道」这类场景。

1. 在左侧配置栏「智能抽取」行，点 **「细目表组卷」** 按钮，打开细目表弹窗。
2. 在弹窗中点 **「加一行」**，每行填：
   - **考点**：可空（不填则不限）；支持多值，逗号分隔，OR 匹配。
   - **题型**：单选 / 多选 / 填空 / 解答 / 不限。
   - **难度**：不限 / 普通题 / 易错题 / 挑战题 / 强基题。
   - **解法**：可空。
   - **题量**：该行要几道。
3. 点 **「按细目表抽题入篮」**。
4. 系统按「题型 + 难度 + 知识点 + 解法」从题库选最久没用过的题（鲜活优先），跨行自动去重，回填到右侧试卷。
5. 结果区会显示「已凑齐 X/Y 道」或「缺口 Z 道」（题库里符合条件的题不够时），方便你补录或放宽条件。关闭弹窗后右侧 A4 画布即时刷新。

### 方式 C：AI 一键抽题（自然语言）

在左侧配置栏底部有一个 **智能抽卷输入框**，例如输入：

> 帮我抽 5 道难度中等的函数选择题

点 **「智能抽取」**。可用 **「避重策略」** 下拉控制：
- **自动**：由模型判断。
- **优先未用过**：尽量选入库后没组过卷的题。
- **优先旧题**：优先选高频旧题（适合复习卷）。

> 提示：纯浏览、公式预览、组卷排版不需要 API 密钥；AI 抽题需在右上角【设置】里填入 DeepSeek 等密钥。

## 3. 试卷模板与预设

在右侧操作栏点 **「选择试卷模板」** 按钮，打开模板弹窗：

- **内置模板**（一键应用）：

| 模板 | 总分 | 结构 |
| --- | --- | --- |
| 周测卷 | 100 | 选择 + 填空 + 解答 |
| 月考卷 | 150 | 高考式 19 题（含答题卡） |
| 随堂练 | 50 | 纯解答 |

- **应用粒度**：套用模板**只覆盖卷面参数**（版式 / 目标总分 / 默认留白），**不会清空已选试题篮**，也不会自动抽题。
- **细目表可选加载**：若模板带细目表，应用确认页会出现「同时加载模板细目表」勾选项——勾选仅把细目表载入细目表弹窗（供你改知识点/难度后手动抽题），不勾选则完全不加载。
- **可编辑 / 可新增**：每个内置模板可「编辑」；弹窗右下角 **「新增预设」** 打开编辑器，逐项填名称/版式/总分/留白/细目表行，保存即存入个人预设（本地数据库，重装不丢）。
- **个人预设**：弹窗内「个人预设」列表可「应用 / 编辑 / 删除」。

---

## 4. 组卷体检（手动触发）

在右侧操作栏点 **「组卷体检」** 按钮，弹出评估报告（**不强制**，纯手动触发，保存试卷前不会自动弹）：

- **总分对齐**：设好「目标分」后，显示「已对齐目标」或「差 ±N 分」。
- **题型分布**：各题型的题数 / 分值 chips。
- **难度分布**：易 / 中 / 难占比条。
- **知识点覆盖**：本卷涉及的知识点清单。
- **疑似重复题**：同源或同题干开头的题会预警，避免一份卷里出现重题。

---

## 5. 分值与排版微调

选中题目后，在题目卡片上可：

- **改分值**：入卷题卡上的「分值」输入框直接改。
- **批量设分**：右侧画布控制栏「批量设分」选题型 + 填分值 + 应用，一次性给某题型所有题设分。
- **留白**：画布控制栏「留白」下拉（标准 7cm / 紧凑 3cm / 不留白 0cm），导出的答题区会预留空白书写空间。

右侧 A4 画布会自动：
- 按 **题型分段**（单选/多选/填空/解答）；
- 全卷 **连续编号**；
- 段内支持 **拖拽排序**（在「已选试题」标签下用上移/下移）。

---

## 6. 保存与导出

画布控制栏底部按钮：

- **保存试卷**：把当前卷存到本地数据库，可在 **「历史试卷库」** 查阅 / 载入 / 二次编辑。
- **PDF 预览**：编译并打开试卷 PDF。
- **Word 导出**：导出可编辑 Word 试卷（保留原生公式）。
- **LaTeX 打包**（高考 19 题模板专属）：导出 LaTeX 源码 + 插图 + 编译好的 PDF 全套文件。
- **答题卡 PDF 预览**（高考 19 题模板专属）：生成 A3 双面答题卡。

> 导出 PDF 需要本机安装 LaTeX 环境；纯浏览、组卷、保存不需要。

## 7. 常见问题（FAQ）

**Q1：我在题库工作台点了标签筛选，题目只显示在左边一小条，看不全？**  
这是旧布局——左侧 320px 列表只负责「检索」，点题是去中间编辑区看。现已优化：
- 题卡显示知识点/解法标签，悬停点 **「展开全文」** 看完整题干；
- 题卡右上角直接 **「入卷」**；
- 顶部 **「试题篮」** 提示条显示已选数量并一键「去组卷」。
推荐直接切到 **组卷工作台**，那里左侧是全宽「全库试题流」，一屏看多道题、直接加卷，体验最清晰。

**Q2：同一道题会重复进卷吗？**  
不会自动重复（入卷时按 id 去重）。但不同来源的相同题可能都被录入题库——入库环节已做相似度查重（阈值 0.92），重复录入会提示「仍入库 / 跳过」，从源头减少重题。组卷体检也会对同卷内的疑似重题报警。

**Q3：拆卷（PDF/Word 拆解）和组卷什么关系？**  
拆卷是把一份现成试卷拆成单题存进题库（顶部「导入试卷」）；组卷是从题库里挑题拼成新卷。流程通常是：拆卷入库 → 组卷挑选 → 排版导出。

**Q4：刷新页面后我的卷还在吗？**  
试题篮和细目表存在浏览器本地（localStorage），刷新不丢；但正式保存请用「保存试卷」写入数据库。

**Q5：三个工具（模板 / 细目表 / 体检）在哪？**  
都是触发式弹窗，不占画布空间：细目表组卷在左侧「智能抽取」行旁的按钮；试卷模板、组卷体检在右侧操作栏的按钮。点击即弹窗，关闭后 A4 画布始终占满右侧、试卷预览清晰可见。

## 8. 操作速查

```
进入：小陈的数学宝藏 ▾ → 组卷工作台
选题：左侧全库试题流「加入试卷」按钮 / 「已选试题」标签排序
凑题：左侧「细目表组卷」按钮弹窗 → 按细目表抽题入篮  /  左侧 AI 抽题框输入需求
套模板：右侧「选择试卷模板」按钮弹窗 → 周测/月考/随堂练，或新增/编辑个人预设
把关：右侧「组卷体检」按钮弹窗（总分/题型/难度/知识点/重题，手动触发不强制）
设分：卡片分值框 / 画布「批量设分」 / 「留白」
出卷：保存试卷 → PDF 预览 / Word 导出 / LaTeX 打包 / 答题卡
```
