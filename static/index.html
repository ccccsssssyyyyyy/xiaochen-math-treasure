                            多模态与安全说明：
                            所有 API 配置信息均直接持久化保存在您的本地根目录 .env 文件中。通过 硅基流动(SiliconFlow) 或 阿里百炼(Alibaba Bailian) 调用 Qwen 多模态视觉模型，能够实现极其高精准度的行内公式与混排题干识别。
                        
                    

                

                

                
                

                    

                        

                            
                            免费模型配置（自动路由）
                        

                        
配置后，拆解与分类将自动评估难度：简单/中等走免费大模型，困难自动回退付费。Key 复用『API 接口设置』里对应供应商的 Key。

                    


                    

                        
                        

                            
                            

                                
                                

                            

                        


                        
                        

                            
                            

                                
                                

                            

                        


                        
                        

                            
                            

                                
                                

                            

                        


                        
                        

                            
                            

                                
                                

                            

                            
用于拆解前判断难度的小模型，消耗极低，建议保留免费大模型。

                        

                    


                    

                        
                        路由规则：免费模型留空 = 全程走付费；已配置且 Key 有效时，简单/中等难度自动用免费大模型，困难文档自动回退付费；若免费 Key 缺失则安全回退付费，绝不裸奔。
                    

                

                

                
                

                    

                        

                            

                                
                                自定义维度 JSON 配置编辑器
                            

                            
可在此处编辑自定义的题型、难度等级（含颜色）以及层级教学大纲树状结构。

                        

                        

                            预设模板一键载入：
                            
                            
                            
                            
                        

                    

                    
                    

                        
                    

                    
                    

                        
配置说明：

                        
1. question_types: 题型列表。例如：{"value": "single_choice", "label": "单选题"}。

                        
2. difficulties: 难度等级列表。必须包含 value, label 和 color 属性。color 使用 Tailwind CSS 类名控制徽章样式。

                        
3. curriculum: 树状大纲目录结构。格式为："学段名称": {"章节名称": ["知识点/小节1", "知识点/小节2"]}。修改并保存后，AI 智能分类与试卷智能拆解将立刻感知并应用新大纲！
